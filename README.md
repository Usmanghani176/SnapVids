# SnapVids — All-in-One Social Media Video Downloader

A fast, modern web application to download videos and audio from **YouTube**, **TikTok**, **Instagram**, and **Facebook** with live percentage progress tracking.

## Features
- **Multi-Platform Support:** YouTube (Videos & Shorts), TikTok (No Watermark), Instagram (Reels & Posts), and Facebook (Watch & Reels).
- **Multiple Quality Options:** Download in 1080p, 720p, 480p, 360p HD MP4, or Audio Only (M4A/MP3).
- **Live Download Progress Bar:** Real-time 0% to 100% progress, download speed, and ETA before saving to browser downloads.
- **Modern Dark & Light Theme:** Clean glassmorphism UI with clipboard paste and recent download history.

## Getting Started

npm install
npm start

Then open http://localhost:3000 in your browser.
